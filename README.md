# SnowgLove

This is visual novel made with Ren'Py. The main idea was to make a chirstmas themed parody dating-sim. You play as an astronomer visiting the North Pole on December to observe the aurora borealis, In the meantime you'll see various peculiar characters.

## Art

All character sprites were made by me using Krita. All backgrounds are free to use images I found on pinterest.

## Music

All music and sound effects are youtube videos converted to .mp3 using Y2Mate.
